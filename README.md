# 感染圍堵模擬模型

## Proposal Report

### 動機與目標
<!-- 說明為什麼想做這個專題 -->

此模型源自現實中的病毒擴散與圍堵，可以應用在現實中如防治傳染性疾病、阻止電力或水利等基礎設施的故障擴散影響，也能應用於資訊領域上如防堵病毒、抑制假訊息等問題，應用範圍廣泛。

專案的目標為做出一個簡易的模型，能夠對病毒的感染擴散以及防堵進行模擬，並且加入一些現實中情境的背景要素，強化模型的模擬功能。

### 競品比較

1.&emsp;瘟疫公司:模擬病毒擴散的遊戲。遊戲中玩家扮演病毒的角色，目標為將疾病擴散至整張圖。此模型則相反，簡化病毒擴散的行為並且透過操作圍堵病毒。

2.&emsp;滲流理論(Percolation Theory):研究是否存在貫穿圖的路徑。可用於模型中的牆壁密度設定，讓隨機生成的圖保有一定連通性。

### 預期功能
<!-- 列出預計實作的功能 -->

1.&emsp;模擬在二維平面、給定圖上的病毒擴散。

2.&emsp;模擬牆的放置(阻斷路徑)，讓病毒無法透過此條邊。

3.&emsp;嘗試在有限資源下(時間、牆的數量等)最小化病毒擴散範圍。

### 使用技術
<!-- 使用的語言、框架、工具等 -->

預計使用C++撰寫。在基礎的原型做出來之後，可以嘗試利用OpenCV、SFML等框架視覺化圖形。

### Prototype 預計可驗證內容

以文字介面呈現地圖目前狀況，並能模擬病毒的擴散與牆壁的放置。


## Prototype Report

### 目前進度
<!-- 完成了什麼 -->

1.&emsp;能夠隨機生成地圖，並能調整地圖的大小、隨機的參數(地圖中牆壁的比例)。

2.&emsp;對X座標和Y座標分別採用常態分佈隨機取數，產生病毒的根源點。能模擬病毒由根源往外的擴散，以及使用者操作放置牆壁的過程。

3.&emsp;每一回合由使用者放置一道牆(在某個地圖格子上)，接著病毒往外擴散一格。重複直到病毒無法再擴散，統計受感染的格子數量。

4.&emsp;地圖用文字介面呈現。

### 遇到的困難
<!-- 遇到什麼問題、如何解決或打算如何解決 -->

1.&emsp;隨機取數的問題:使用static修飾讓種子設定只會被執行一次，並且使用均勻分布生成地圖和常態分布隨機產生病毒初始座標。

2.&emsp;非網格狀圖的視覺化:一般的圖要直接進行視覺化很難，要使用Graphviz等外部軟體輔助。目前先只研究在二維網格上的擴散與圍堵行為。


### 下一步計畫

2.&emsp;嘗試視覺化網格圖，增加易讀性。
