# 感染圍堵模擬模型

## Proposal Report

### 動機與目標
<!-- 說明為什麼想做這個專題 -->

此模型源自現實中的病毒擴散與圍堵，可以應用在現實中如防治傳染性疾病、阻止電力或水利等基礎設施的故障擴散影響，也能應用於資訊領域上如防堵病毒、抑制假訊息等問題，應用範圍廣泛。

專案的目標為做出一個簡易的模型，能夠對病毒的感染擴散以及防堵進行模擬，並且加入一些現實中情境的背景要素，強化模型的模擬功能。

### 競品比較

1.&emsp;瘟疫公司:模擬病毒擴散的遊戲。遊戲中玩家扮演病毒的角色，目標為將疾病擴散至整張圖。此模型則相反，簡化病毒擴散的行為並且透過操作圍堵病毒。

2.&emsp;滲流理論(Percolation Theory):研究是否存在貫穿圖的路徑。可用於模型中的牆壁密度設定，讓隨機生成的圖保有一定連通性。

### 預期功能
<!-- 列出預計實作的功能 -->

1.&emsp;模擬在二維平面、給定圖上的病毒擴散。

2.&emsp;模擬牆的放置(阻斷路徑)，讓病毒無法透過此條邊。

3.&emsp;嘗試在有限資源下(時間、牆的數量等)最小化病毒擴散範圍。

### 使用技術
<!-- 使用的語言、框架、工具等 -->

預計使用C++撰寫。在基礎的原型做出來之後，可以嘗試利用OpenCV、SFML等框架視覺化圖形。

### Prototype 預計可驗證內容

以文字介面呈現地圖目前狀況，並能模擬病毒的擴散與牆壁的放置。

## Final Report

### 專案說明
<!-- 完整描述你的專案做了什麼 -->

這個模型模擬了病毒擴散以及放置牆壁阻擋的過程。系統會隨機生成許多張地圖，每張地圖的每個格子擁有「牆壁」或「健康格子」兩種狀態。接著，系統會選取其中一個格子作為「感染源」，將其設定為「感染格子」，其後開始模型模擬。模擬的過程是回合制，每一回合會由某個演算法自動「放置牆壁」，此格即永久變成「牆壁」。接著，每一格狀態為「感染格子」的格子皆會向外（上、下、左、右）一格的健康格子擴散病毒。如果有某一格是「牆壁」，則不會往那一格擴散。此過程會一直重複執行，直到所有受感染的格子無法再繼續擴散，換言之，所有受感染的格子周圍沒有健康格子。模擬結束時，系統會統計此演算法策略下病毒總共感染的格子數量並且記錄，接著在同一張地圖、同一個感染原設定下，使用下一個演算法進行模擬，直到所有模擬結束後，換成下一張地圖，持續上述模擬過程。

我使用檔案拆分、繼承和多型來實現在同一組地圖裡模擬多種不同策略的圍堵方法，每一個演算法都在一個獨立的.h檔案裡，繼承一個共同的抽象類別，增加了易讀性和簡化加入不同演算法進行測試的流程。

模擬測試執行完成後，系統會在maps資料夾中(如有創建)生成此次模擬的逐張地圖資料(一張地圖一個檔案)，並在results中生成一個地圖檔案以及一個所有演算法測試結果的檔案(表格)。

### 使用方式
<!-- 如何編譯、執行、使用你的程式 -->

下載所有.cpp和.h檔，使用任何c++環境編譯執行。在Constants.h中，有多種參數可以調整，包括:

1.&emsp;隨機生成地圖的牆壁密度、寬度、高度
2.&emsp;總共生成幾張地圖測試
3.&emsp;是否移除病毒根源四周的所有牆壁
4.&emsp;是否開啟讀取地圖模式
5.&emsp;是否在終端輸出每張地圖每個演算法測試時最後的地圖配置
6.&emsp;是否在終端輸出每張地圖每個演算法測試時每回合的地圖變化

在程式碼的資料夾層創建maps和results資料夾，以得到此次測試的所有地圖資料和每張地圖裡每個演算法的最終結果(受感染格數)。

#### 讀取地圖模式使用方法:

&emsp;在Constants.h中設置讀取地圖模式為真，在main中更改讀取檔案的名稱(.txt)。檔案格式如下:

&emsp;三個整數:地圖寬度、地圖高度、感染源數量

&emsp;所有感染源座標(x,y)

&emsp;地圖網格(健康格子:.、牆壁:#、感染格子:V)

&emsp;範例:

&emsp;5&emsp;5&emsp;1&emsp;1&emsp;2

&emsp;#....

&emsp;..#..

&emsp;.V...

&emsp;..#.#

&emsp;.#.#.

&emsp;若無開啟讀取模式，系統會根據Constants中的參數生成一組地圖來測試。


使用者可以創建新的檔案，宣告類別繼承抽象類別BaseAgent，並且override兩個函式，其中getBlockPoint即為選擇牆壁的演算法。之後在main中include新的檔案並且在myAIList中加入新的物件，即能開始測試不同的演算法。
